
# Prioritizing Content Refresh Opportunities Using Machine Learning

## Abstract

This project investigates how machine learning can support content refresh prioritization using search and engagement signals.

---

# Introduction

Content teams often manage thousands of pages.

Machine learning can help prioritize which pages deserve review first.

---

# Data

- FlyRank ML Internship Starter Dataset
- 30,000 pages
- 44 features

---

# Methodology

Model:

- Logistic Regression
- Random Forest

Validation:

- Train/Test Split
- Grouped Validation

---

# Results

Random Forest outperformed the baseline.

Grouped validation produced a more realistic estimate of model performance.

---

# Limitations

- Decision support only
- No causal claims
- Cannot predict Google's algorithm

---

# Recommendations

1. Review declining pages first.
2. Prioritize high-impression pages.
3. Validate recommendations manually.
